# tutorial-TWIST-SPIN
Tutorial for begineers to learn:
- Basics: how to use OnwTech's TWIST/SPIN board
- Communications: how to use the different types of communication to talk with other boards
- PV: how to use the board for photovoltaic panels applications
- MMC: how to use the board to build a brand new MMC !!
